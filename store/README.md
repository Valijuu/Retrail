# Store assets: what is what

Source of truth for rules is `store.sdd`. This file only says where things are.

| Path | What | Source or generated | Goes to the store |
|---|---|---|---|
| `play/text/` | Live Play texts (short, full) | written by hand | yes, pasted in Play Console |
| `ios/text/` | Live App Store texts (name, subtitle, promo, keywords, description, what's new) | written by hand | yes, pasted in App Store Connect |
| `play/screens/raw/` | Raw Android shots (emulator) | taken by hand | no, input for framing |
| `play/screenshots.tsv`, `play/screenshot_frame.html` | Motives, captions, frame (Play) | source | no |
| `play/screenshots/{de,en}/` | Framed Play screenshots, 1080 x 1920 | generated by `tool/render_store_graphics.sh` | yes |
| `play/feature_graphic.html` | Feature graphic template | source | no |
| `play/feature_graphic_{de,en}.png` | Play feature graphic, 1024 x 500 | generated by `tool/render_store_graphics.sh` | yes |
| `play/fgs_demo.mp4` | Foreground-service demo video for the Play declaration | recorded | yes (Play Console form) |
| `play/listing_preview.html` | Local preview of icon, graphic and screenshots together | helper | no |
| `ios/screenshots.tsv`, `ios/screenshot_frame.html` | Motives, captions, frame (iOS) | source | no |
| `ios/screenshots/{de,en}/` | Framed App Store screenshots, 1320 x 2868 | generated by `tool/render_ios_store_graphics.sh` | yes |
| `ios/screenshots_6_3/{de,en}/` | Same images at 1206 x 2622 for the App Store Connect upload field | resized from `ios/screenshots/` | yes (if the 6.9" size is rejected) |

Raw iOS shots come from the `iOS screenshots` workflow (`tool/ios_screenshots.sh`) and stay in `build/`
(ignored). The app icon source is `AppLogo/`, built into the launcher icons by `tool/build_app_icons.py`.
Never put real routes in any of this (repo is public).
