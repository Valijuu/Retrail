# Decision notes

One short note per decision taken after the SpecDD migration, named `NNNN-<title>.md` (`0001-…`, counting up).
Each note has three parts: **Context** (what forced the choice), **Decision** and **Rejected alternatives**
(with why). The spec the decision shaped references the note in its `References` section.

Decisions from before the migration live in `../specs/history/`.
